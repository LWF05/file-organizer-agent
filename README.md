# 资料整理 Agent

一个带完整桌面 GUI 的 Python 文件整理 Agent。它扫描用户选定文件夹的**顶层文件**，给出分类建议；用户可逐项修改，再确认移动。上一次移动可撤销。

## 能做什么

- 选择任意本地文件夹，扫描文件名、扩展名和大小；不读取文件内容，也不递归处理子文件夹。
- 输入整理目标和 2–12 个分类。可使用无需联网的扩展名规则，或选择 DeepSeek 生成语义分类方案。
- 在表格中查看每个文件的目标分类与理由，将不确定项目保留为“待确认”，也可以人工改类。
- 执行前再次确认；不会覆盖同名目标文件；将移动记录保存在所选文件夹内，以便撤销。
- LLM 输出必须通过完整性和分类白名单校验；模型不能直接操作文件。

## 运行环境

Python 3.10 或更新版本。图形界面使用 Python 标准库 Tkinter，**不需要安装第三方包**。

在解压后的项目目录打开 PowerShell：

```powershell
python gui.py
```

先创建一个包含少量测试文件的文件夹，体验完整流程，再处理真实资料。运行程序期间请避免用其他程序同时移动该文件夹里的文件。

## 可选：启用 DeepSeek 分类

本地规则适合按文件类型分类。如果需要根据“高数、英语、编程”等文件名语义分类，可在当前 PowerShell 窗口设置 DeepSeek API Key：

```powershell
$agentKey = Read-Host "输入 DeepSeek API Key" -AsSecureString
$env:DEEPSEEK_API_KEY = [System.Net.NetworkCredential]::new("", $agentKey).Password
python gui.py
```

然后在 GUI 中选择“DeepSeek API”。程序只发送文件名、扩展名、大小、整理目标和允许的分类；**不会上传文件内容**。API 不可用时可改用“本地规则”。请勿把密钥写入代码或提交到 GitHub。接口使用 [DeepSeek Chat Completions](https://api-docs.deepseek.com/zh-cn/api/create-chat-completion/) 的 JSON 输出模式。

## 操作步骤

1. 点击“选择文件夹”，再点击“生成分类方案”。
2. 阅读表格中的目标分类和理由。选中一行，使用“应用修改”人工更改分类；不确定的项目留在“待确认”。
3. 点击“确认并移动文件”，核对提示后执行。分类文件夹会建立在所选文件夹内。
4. 如需撤销，点击“撤销上次移动”。若目标文件被外部程序改变，或原位置已有同名文件，程序会跳过该项。
5. 如果接受上一次的移动结果，可点击“放弃上次撤销记录”，然后制定新方案。

## 设计说明

`agent_core.py` 负责扫描、规则规划、模型结果校验、执行和撤销；`llm.py` 只负责调用模型获取建议；`gui.py` 提供人工审核界面。DeepSeek 请求在后台线程运行，界面不会因网络等待而失去响应。

一次最多处理 100 个顶层文件。文件夹内容在预览后如果发生变化，执行会拒绝并要求重新扫描。符号链接和子文件夹均跳过。撤销记录只覆盖最近一批操作。

## 测试

```powershell
python -m unittest discover -s tests -v
```

测试覆盖分类名安全、顶层扫描、模型编造文件拦截、同名目标保护、执行和撤销。在线模型效果需使用真实文件名另做人工评测；不要将规则测试结果当作模型准确率。

## 项目演示建议

准备一个只包含测试文件的文件夹，例如 `高数作业.pdf`、`英语单词.txt`、`实验截图.png`、`main.py`、`未命名资料.bin`。展示“扫描—预览—修改—执行—撤销”流程，并解释模型输出如何经过程序校验。这比只展示分类结果更能说明 Agent 的可靠性设计。
